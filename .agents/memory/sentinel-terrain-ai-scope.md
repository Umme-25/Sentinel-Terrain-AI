Sentinel Terrain AI is an AI-powered landslide risk assessment and early-warning frontend for an IBM Hackathon. The user explicitly scoped the initial work to a responsive frontend foundation; do not add ML predictions, a Flask backend, real alerts, or authentication unless they ask for that later.

**Why:** The user wants the project delivered in deliberate phases and does not want Phase 2 started before Phase 1 is accepted.

**How to apply:** Keep placeholder pages explicit about demo-only status and avoid fabricated live risk or alert data.
